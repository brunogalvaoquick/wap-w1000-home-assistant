# Código de conduta

Este é um projeto pequeno, mantido por hobby, para quem tem o robô WAP W1000 e
quer usar no Home Assistant. Para todo mundo se sentir à vontade:

- **Seja respeitoso.** Trate as pessoas com educação, mesmo discordando.
- **Sem ofensas, assédio ou discriminação** de qualquer tipo (gênero, orientação,
  raça, religião, idade, deficiência, nível de experiência etc.).
- **Ajude quem está começando.** Ninguém nasceu sabendo o que é DP, LocalTuya ou YAML.
- **Mantenha o foco no assunto** do repositório.
- **Não publique dados sensíveis**, seus ou de outras pessoas (local_key, IP público,
  senhas, endereços).

Comentários, issues ou PRs que desrespeitarem estas regras podem ser editados,
fechados ou removidos, e quem insistir pode ser bloqueado.

Para relatar um problema de conduta, abra uma issue ou fale com o mantenedor pelo
perfil do GitHub [@brunogalvaoquick](https://github.com/brunogalvaoquick).
