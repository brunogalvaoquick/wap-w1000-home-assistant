# Acessibilidade

- A documentação é texto simples em Markdown, com tabelas e títulos, para funcionar
  bem com leitores de tela e tradutores automáticos.
- Os avisos das automações vão por **notificação de texto** no celular, que o
  sistema do celular pode ler em voz alta. Dá para trocar por aviso de voz numa
  caixa de som (ação `tts.speak`) para quem prefere ouvir.
- Os textos estão em português do Brasil, com resumo em inglês no README.

Se algo aqui é difícil de usar para você, abra uma issue contando o que atrapalha.
